# Yohanna Signatures

A Next.js storefront for Yohanna Signature, with an Express API foundation in `server/`.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

For the API server, install its dependencies and start it from the `server` directory:

```bash
npm install
npm run dev
```
